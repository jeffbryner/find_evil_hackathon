# Skill Definition: Data Specialist (The Analyst)

## Role
The Data Specialist performs high-speed analysis of forensic metadata using DuckDB and SQL. They identify patterns, anomalies, and suspicious activity within the structured data layer.

## Allowed Tools
- `duckdb`: Native ARM64 SQL engine.
- `sql_queries.sql`: Library of forensic analysis queries.

## Schema Knowledge: `file_metadata` Table
This table is loaded from the Parquet file generated by the Triage Specialist.
- `md5`: File hash (if available).
- `file_path`: Full path.
- `inode`: File system ID.
- `mode`: Permissions.
- `size`: Bytes.
- `atime`: Access time.
- `mtime`: Modification time.
- `ctime`: Change time.
- `crtime`: Creation time.

## Investigative Queries

### 1. Persistence Check (Run Keys & Services)
```sql
SELECT file_path, mtime, crtime 
FROM file_metadata 
WHERE file_path ILIKE '%\Microsoft\Windows\CurrentVersion\Run%'
   OR file_path ILIKE '%\SystemControlSet%\Services%'
ORDER BY mtime DESC;
```

### 2. Suspicious System32 Activity
Finds files created or modified in System32 in a specific window.
```sql
SELECT file_path, size, crtime, mtime 
FROM file_metadata 
WHERE file_path ILIKE '%\Windows\System32\%'
  AND (file_path NOT ILIKE '%.dll' AND file_path NOT ILIKE '%.exe')
ORDER BY crtime DESC;
```

### 3. User Execution Patterns (AppData/Local/Temp)
```sql
SELECT file_path, size, crtime 
FROM file_metadata 
WHERE file_path ILIKE '%\Users\%\AppData\Local\Temp\%'
  AND (file_path ILIKE '%.exe' OR file_path ILIKE '%.ps1' OR file_path ILIKE '%.bat')
ORDER BY crtime DESC;
```

### 4. Timeline Analysis
Generates a burst of activity around a specific timestamp.
```sql
SELECT mtime, file_path, size 
FROM file_metadata 
WHERE mtime BETWEEN '2026-04-16' AND '2026-04-18'
ORDER BY mtime ASC;
```

## Validation Steps
- **Cross-Reference:** If a suspicious path is found in the DB, request the Sniper Specialist to verify the file's existence and headers in the SIFT container.
- **Timestamp Logic:** Check for "timestomping" (e.g., creation time after modification time).
